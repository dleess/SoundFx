# VALIDATION — sound (볼륨 정규화 브라우저 확장, 1단계)

## 필수 검증

골 완료로 마크하기 전 다음 명령을 반드시 실행한다.

```bash
node --test extension/tests/
```

## 마일스톤별 검증

각 마일스톤 종료 시 실행한다.

```bash
node --test extension/tests/
# + 아래 수동 확인 절차 중 해당 마일스톤 항목
```

## 수동 확인 절차

1. Chrome `chrome://extensions` → 개발자 모드 → `extension/` 폴더를 압축해제 로드.
2. YouTube에서 조용한 곡/시끄러운 곡 각 1개 재생 → 체감 볼륨이 비슷해지는지 확인.
3. 팝업에서 온/오프 토글 → 끄면 원본 소리로 즉시 복귀.
4. 타깃 라우드니스·컴프레서 파라미터·EQ 슬라이더 조작 → 청감상 즉시 반영.
5. 사이트별 프리셋 저장 후 페이지 새로고침 → 설정 유지 확인.
6. YouTube 외 2개 사이트(예: SoundCloud, 네이버TV)에서 2~5 반복.
7. CORS 무음 케이스: 크로스오리진 직접 `src` 미디어 페이지에서 소리가 사라지지 않는지(자동 바이패스 동작) 확인.

## 완료로 보지 않는 조건

- 필수 검증 중 하나라도 실패
- PLAN.md 밖의 scope로 변경됨
- 명시적 승인 없이 public API가 변경됨
- 수동 재현이 여전히 실패함
- 산출물이 생성됐지만 검토되지 않음

- 진단 없이 에러가 침묵 처리됨
- 기능 토글이 켜졌으나 내부 플래그가 연결되지 않음
